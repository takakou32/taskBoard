# タスクボード

6人チーム向けの週次タスク管理看板。**サーバー不要・ローカル起動のデスクトップアプリ**で、
データ本体は社内NAS上の共有ファイル（JSON）に置いて共有します。

- UI: HTML / CSS / JavaScript（ドラッグ&ドロップ看板）
- ホスト・データ層: **PowerShell + WebView2**（追加ランタイムのインストールは原則不要）
- 運用: 1週間=1スプリント。週の大目標に達成／持ち越しステータス、継続目標、週末の締めで次週へ引き継ぎ。

---

## 起動のしかた

**利用者はこの2つをダブルクリックするだけです。**

| ファイル | 用途 |
| --- | --- |
| **タスクボード.bat** | 本体を起動します。ふだんはこちら。 |
| **タスクボード_UI確認.bat** | 画面だけをブラウザで開きます。WebView2 不要・**保存はされません**。 |
| **マニュアル.html** | 利用者向けの使い方。ダブルクリックでブラウザが開きます。 |

デスクトップにショートカットを作って配ると便利です。
起動に失敗したときは原因の候補を表示して画面が止まるので、メッセージを読めます。

PowerShell から直接動かす場合:

```powershell
.\start.ps1            # 本体
.\start.ps1 -Preview   # UIのみ
```

## 準備は不要です

表示に必要な WebView2 の DLL（約1.2MB）は `lib\` に同梱しています。
**clone またはフォルダをコピーしたら、そのまま タスクボード.bat で起動できます。**
インターネット接続もビルドも要りません。

`config.local.json` が無ければ `data\sample`（W28〜W30の見本）を使うお試しモードで動きます。

> DLL を更新したいときは `setup-webview2.ps1 -Force` を実行してコミットしてください。
> 万一 `lib\` の DLL が失われていた場合は、起動時に自動で取得を試みます（要インターネット）。

## 本番運用（NAS共有）

1. NASの共有フォルダに **`data\template\board.json` をコピー**する
   （例: `\\NAS-SERVER\share\taskboard\data\board.json`）。
   中身は空です。`weeks\` などのフォルダはアプリが起動時に自動で作ります。
2. `config.sample.json` を `config.local.json` にコピーし、`dataRoot` にその共有パスを設定:

   ```json
   { "dataRoot": "\\\\NAS-SERVER\\share\\taskboard\\data" }
   ```
3. 各PCに、このフォルダ一式と `config.local.json` を配り、**タスクボード.bat** から起動してもらう。
   DLLは同梱されているので、配布先での準備作業はありません。
4. 起動したら画面右上の **⚙** からメンバーと案件を登録する。

詳しくは [data\template\README.md](data/template/README.md) を参照してください。

> `data\template` や `data\sample` を `dataRoot` に直接指定しないでください。
> git pull で実データが上書きされる恐れがあります。必ずNAS上にコピーして使ってください。

フォルダごとNAS上に置いて、各PCからそこの bat を直接叩く運用でも動きます
（bat は `pushd` を使っているので `\\サーバ名\共有名\...` のUNCパスから実行できます）。
ただし各PCにコピーしたほうが起動は速くなります。

## データの形

リポジトリ内の `data\` には2つ入っています。

| | 用途 |
| --- | --- |
| `data\sample\` | 動作確認用の見本（W28〜W30、メンバー6名） |
| `data\template\` | **本番用の空データ。NASにコピーする元** |

実際に使われるデータの構成:

```
<dataRoot>\
  board.json            … メンバー・案件・継続目標・設定（共有・小さいファイル）
  weeks\
    2026-W30.json       … その週の目標とタスク（1週1ファイル）
    2026-W29.json
  .locks\               … 書き込み調停用のロック（自動生成）
  backup\<日付>\        … 日次の世代バックアップ（自動）
```

1週1ファイルにしているのは、同時編集の影響範囲を1週間ぶんに閉じ込め、
締めた過去週を凍結してバックアップ被害を限定するためです。

## 使い方のポイント

- **新規タスク**: ツールバーの「＋ 新規タスク」、または未着手列の「＋ カードを追加」。カードをクリックすると同じ画面で編集・削除できます。
- **並び替え**: カードは列内でも列をまたいでも、落としたい位置に線が出るのでそこへドロップします。順序はそのまま保存され全員に共有されます。
- **週の目標**: 目標レーンの「＋ 目標を追加」。記号（A/B/C…）は自動で振られます。各目標の「✎」から改題・状態変更・削除ができます。**目標を削除してもタスクは消えず、紐づけだけが外れます。**
- **継続目標**: 目標レーン「継続目標」見出しの「⚙」から管理します。記号はZ側から割り当てるので週目標のA/B/Cと混ざりません。使わなくなったものは削除より**休止**を推奨します（削除すると未締めの週のタスクから紐づけが外れます。締めた週の記録は変わりません）。
- **メンバーと案件**: ツールバー右の「⚙」から追加・改名・休止／削除。メンバーのアバターをクリックすると色と表示文字（1文字）を変えられます。色は追加時に未使用のものが自動で割り当てられます。
  - チームから外れた人は**休止**を推奨します。休止すると新しい割り当ての候補から外れますが、過去の担当記録もその週の看板表示も残ります。削除すると未締めの週から担当が外れます（締めた週の記録は変わりません）。
- **週を締める**: ツールバーの「週を締める」。目標ごとに達成／持ち越しを選び、運ぶタスクにチェックを入れて実行すると、次週が作られてそのまま開きます。2週以上の連続持ち越しは赤字で警告します。
- **編集中の衝突**: 誰かがカードを開いている間、他のPCではそのカードが灰色になり「◯◯が編集中」と出ます（アプリが落ちても10分で自動解除）。
- **切断時**: 共有フォルダに書けなくなると上部に赤い帯が出て閲覧のみに切り替わり、復帰すると自動で戻ります。他のPCの更新は5秒ごとに取り込まれます。

## 開発時の注意

`.ps1` は **UTF-8 (BOM付き)** で保存してください。BOMが無いと PowerShell 5.1 が
Shift-JIS と誤読し、日本語コメントの箇所で構文エラーになって起動しなくなります。

## 動作要件

- Windows 10 / 11、Windows PowerShell 5.1（標準搭載）
- WebView2 ランタイム（多くの環境に既在。無ければ一度きりの導入）
