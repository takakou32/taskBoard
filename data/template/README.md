# data\template — サーバー（NAS）に置く空のデータ

本番運用を始めるときは、**このフォルダの中身をNASの共有フォルダにコピー**してください。
中身は空の `board.json` ひとつだけです。週のファイルやロック用フォルダは
アプリが起動時に自動で作ります。

## 手順

1. NASに置き場所を作る（例: `\\NAS-SERVER\share\taskboard\data`）
2. このフォルダの **`board.json` をそこにコピー**する（この README はコピー不要）
3. リポジトリ直下の `config.sample.json` を `config.local.json` にコピーし、
   `dataRoot` にその共有パスを書く

   ```json
   { "dataRoot": "\\\\NAS-SERVER\\share\\taskboard\\data" }
   ```
4. `タスクボード.bat` から起動
5. 画面右上の **⚙** からメンバーと案件を登録する

以降、週のファイルは自動で作られていきます。

## コピー後にアプリが作るもの

```
<NASの共有フォルダ>\
  board.json          … コピーしたもの（メンバー・案件・継続目標）
  weeks\              … 週ごとのファイル（自動生成）
  .locks\             … 書き込み調停用（自動生成）
  backup\             … 日次バックアップ（自動生成）
```

## board.json について

最初は空です。メンバーと案件はアプリの **⚙** から登録するのが簡単ですが、
人数が多い場合は直接書いても構いません。

`boardName` にチーム名を入れると、画面上部に「タスクボード — 開発1課」のように表示されます。
空のままでも問題ありません。

記入例は `..\sample\board.json` を参照してください。

> **注意**: このフォルダを直接 `dataRoot` に指定しないでください。
> リポジトリを更新（git pull）したときに、実データが上書きされる恐れがあります。
> 必ずNAS上の別の場所にコピーして使ってください。
